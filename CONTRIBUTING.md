# Contributing

This repository is marketing and documentation for a closed-source,
proprietary application — it isn't an open-source project, so there's no
source code here to contribute to and no pull requests for application
features will be accepted.

**Found a typo or a broken link in these docs?** Feel free to open a
small PR or use the "Documentation issue" template — that's genuinely
welcome.

**Want to suggest an app feature or report a bug?** That goes through the
official support channel for customers — see [SUPPORT.md](SUPPORT.md),
not a pull request here.
