# Support

This repository is documentation-only and **does not accept GitHub Issues
or Pull Requests for the application itself** — there's no code here to
patch. See below for where things actually go.

## If you're not a customer yet

Questions about features, pricing, or whether T58 fits your use case:
check **[FAQ.md](FAQ.md)** first, then reach out through the official
Whop listing:

**[whop.com/t58-trading/t58-backtesting-engine](https://whop.com/t58-trading/t58-backtesting-engine/)**

## If you're an active customer

Support for the application itself (installation, bugs, feature
requests, account/billing questions) is handled through the official
support channel provided at purchase via Whop — **not** through this
GitHub repository. That keeps support tied to verified customers and
keeps response times faster than a public issue tracker would allow.

## Reporting a documentation issue

If something in this *documentation* repo (README, feature list, broken
link, typo) is wrong or unclear, feel free to open an issue here using
the "Documentation issue" template — this is the one thing this repo's
issue tracker is actually for.

## Security disclosures

If you believe you've found a security issue in the application, please
do not open a public GitHub issue. Report it privately through the
contact channel provided at purchase via Whop so it can be addressed
before any public disclosure.
